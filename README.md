## About the Project
SANDHU PORTFOLIO is a personal website created to showcase my technical skills, projects, educational background, and professional interests. It provides a central place to explore my work, discover my learning journey, and connect with me professionally.
The project focuses on a clean visual presentation, responsive layouts, intuitive navigation, and an accessible browsing experience across different screen sizes.

## Key Features
* Modern and professional user interface
* Responsive layout for mobile, tablet, and desktop
* Personal introduction and About section
* Technical skills showcase
* Project portfolio and project highlights
* Education and professional journey
* Resume access
* Social media and professional profile links
* Contact section
* Mobile layout improvements and responsive styling
